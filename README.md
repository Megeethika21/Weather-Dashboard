# Weather Dashboard 🌦️

A simple weather dashboard application built using HTML, CSS, and JavaScript.

This application fetches live weather data using the OpenWeather API and displays temperature, humidity, wind speed, and weather conditions for any searched city.

## Features
1. Search weather by city
2. Real-time weather data
3. Temperature display
4. Humidity and wind speed details
5. Responsive user-friendly UI

## Technologies Used
- HTML
- CSS
- JavaScript
- OpenWeather API
